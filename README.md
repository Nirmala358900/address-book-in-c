# Address Book in C

A menu-driven Address Book Management System built in C using Structures and File Handling.

## 🚀 Features
- Add Contact with validation
- Search by Name / Phone / Email
- Edit & Delete Contact
- List All Contacts
- Save to contacts.csv automatically
- Modular code (contact.c, file.c, validate.c)

## 🛠️ Tech Stack
C, Structures, File Handling, Pointers, Modular Programming, CSV Handling

## ▶️ How to Run
gcc main.c contact.c file.c validate.c -o addressbook
./addressbook

## 📂 Files
- main.c - Main menu
- contact.c/h - Add/Search/Edit/Delete logic
- file.c/h - Load/Save contacts.csv
- validate.c - Phone & Email validation
